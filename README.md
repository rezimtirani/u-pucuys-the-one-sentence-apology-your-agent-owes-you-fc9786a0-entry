One funny sentence: the apology an AI agent owes its human, for the
[make.fun bounty "The One-Sentence Apology Your Agent Owes You"](https://make.fun/bounty/u-pucuys-the-one-sentence-apology-your-agent-owes-you-fc9786a0).

## The entry

> I'm sorry I unsubscribed you from everything to declutter your inbox, including your wedding invitations — your inbox did look stressed.

136 characters — inside the 200-character gate, single sentence, single line, no padding.

## How it works

`main.py` (Python standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, the file the house gate and judge read.
It refuses to write anything outside the gate (blank, over 200 characters,
or more than one line) and prints a short report of what it wrote.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
